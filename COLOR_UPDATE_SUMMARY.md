## 🎨 Technical Implementation

### Tailwind CSS v4
Used `@theme` directive in `src/index.css`:

```css
@theme {
  --color-navy-50: #f0f4f8;
  --color-navy-700: #334e68;
  ... (all color variables)
  --color-brown-600: #8b6f52;
  --color-cream-50: #fefdfb;
}
```

### Benefits:
- Consistent colors across entire site
- Easy to maintain
- Fast performance
- Type-safe in TypeScript
