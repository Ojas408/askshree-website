## 🔧 Connecting Domain to Hosting

### For Vercel:
1. Go to your project in Vercel
2. Settings → Domains
3. Add your domain (e.g., askshree.com)
4. Vercel will give you DNS records
5. Add these records in your domain registrar:
   ```
   Type: A
   Name: @
   Value: 76.76.21.21
   
   Type: CNAME
   Name: www
   Value: cname.vercel-dns.com
   ```

### For Netlify:
1. Site settings → Domain management
2. Add custom domain
3. Update your DNS:
   ```
   Type: A
   Name: @
   Value: 75.2.60.5
   
   Type: CNAME
   Name: www
   Value: [your-site].netlify.app
   ```
